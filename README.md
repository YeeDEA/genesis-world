**진행 기간:** 2026년 8월 · *git 이력은 공개 시점의 단일 커밋부터 시작합니다.*

> **재미로 만든 사이드 프로젝트입니다.** 연구·포트폴리오용 작업이 아니라, 인공생명·신경진화가 한 파일 안에서 어디까지 돌아가는지 궁금해서 주말에 만들어 본 장난감이에요.
> *Just-for-fun side project — not research, just a weekend toy.*

브라우저 탭 하나에서 돌아가는 제로-플레이어 인공 생태계. 의존성 0, 빌드 0, 파일 1개.

## 실행
`index.html`을 브라우저로 열거나:
```
npx -y http-server . -p 5199
```

## 무엇이 일어나는가
- 시드 기반 절차적 행성(fBm 노이즈): 바다·해안·산맥·비옥도가 매번 다르게 생성
- 생명체마다 **6→5→3 신경망 두뇌**와 유전자(크기·속도·감각·육식성·번식력·수명·색)
- 먹고, 사냥하고, 번식하며 유전자와 두뇌 가중치가 **변이**됨 — 자연선택만으로 진화
- 유전 거리 기반 **종 분류**: 신종 출현·멸종이 한국어 연대기에 기록됨
- 시체는 땅을 비옥하게, 과밀은 페널티 — 생태계가 스스로 균형을 잡음
- 전멸하면 세계가 다시 생명을 틔움 (영원히 끝나지 않음)

## 관찰 요소 (시드 자랑거리)
- **세계 유형**: 시드마다 판게아형/대륙 분리형/다도해형/군도형 × 풍요/척박 판정
- **종 도감**: 현존 종 실시간 순위, 지배종 👑, 초식🌿/포식🦴 구분
- **명예의 전당**: 최장수 개체·최다 자손·인구 피크·전설 수·멸종 종 수
- **전설 개체**: 자손 7을 남기면 이름(★)을 얻고, 죽음까지 연대기에 기록됨
- **지배종 교체 사건**: 한 종이 세계를 장악하면 연대기에 남음
- 선택한 개체의 **이동 궤적**이 그려짐

## 희귀 이벤트 (시드마다 다른 역사)
E600 이후 확률적으로 발생. 개입하지 않으면 같은 시드에서 같은 순서로 재현됨.
- 🌋 **화산 분출** — 고지대 폭발, 주변 몰살 후 화산재가 땅을 비옥하게
- ❄ **빙하기** (1600 시대) / 🌸 **대번영기** (1000 시대) — 초목 성장률 급변, 화면 틴트
- ☄ **변이 폭풍** (800 시대) — 유성우로 변이 폭 3배, 신종 분화 가속
- 🦠 **역병** (900 시대) — 최다 종이 병들어 서서히 쇠락
- 🌊 **대해일** — 해안 개체 몰살
- 🏝 **신대륙 융기** (초희귀) — 바다에서 새 땅이 솟아 지형 자체가 변함
- 👹 **괴수 출현** — 진화가 크기 1.85+ · 육식 75%+ 개체를 낳으면 발동
- 🔥 **불사조** — 개체 1마리까지 몰렸던 종이 15마리 이상으로 부활
- ★ **전설 개체** — 자손 12를 남기면 이름을 얻음
진행 중인 재해는 HUD 배지(남은 시대 카운트다운)로 표시.

## 멍때리기 모드
- **낮/밤 주기**: 세계가 천천히 어두워지고 새벽·황혼엔 주황빛이 스침 (한 주기 ≈ 4200 시대)
- **떠다니는 구름**, 가장자리 비네트, 탄생 파문·죽음의 빛 파티클
- **젠 모드**: 8초간 입력이 없으면 모든 UI가 스르르 사라짐 (마우스를 올리면 그 패널만 복귀)
- 🔊 **앰비언트 사운드**: 저역 드론 위에 탄생마다 펜타토닉 음이 하나씩, 대사건엔 저음 붐

## 조작 (최소 개입 관찰)
- 클릭: 개체 관찰(에너지·유전자·세대) · Space: 일시정지 · 1×/4×/16× 배속 · ☄: 운석 대멸종
- HUD의 시드 클릭 → **공유 링크 복사** (`?seed=xxx`로 열면 같은 행성이 재현됨)
